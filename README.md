## 설치 방법

1. 위 Releases 페이지에서 `OrangeTalk.Setup.x.x.x.exe` 를 내려받습니다.
2. 파일을 더블클릭해 설치 마법사를 실행합니다.
3. Windows SmartScreen 또는 백신이 경고를 표시할 수 있습니다(코드 서명 미적용 상태). 아래 안내대로 진행하세요.

### Windows SmartScreen 우회

1. SmartScreen 창에서 **추가 정보** 클릭 → **실행** 버튼 클릭
2. 설치 후 정상 실행됩니다.

### 백신(안랩 V3 등) 격리

일부 학교 PC 에서 백신이 설치 직후 파일을 조용히 격리해 **설치는 성공했지만 실행 파일이 사라지는** 경우가 보고되었습니다. 해당 증상이 발생하면 아래 중 하나를 시도해주세요.

- 백신에서 **OrangeTalk** 폴더(`%LOCALAPPDATA%\Programs\OrangeTalk`) 를 **예외**(허용) 등록
- 개발자에게 문의해 오탐 신고를 요청

## 자동 업데이트

v1.0 부터 앱 내부에 자동 업데이트가 포함되어 있습니다.

- 앱 실행 시 새 버전을 자동으로 확인·내려받습니다.
- 내려받기가 끝나면 **다음 종료 시** 자동으로 설치됩니다.
- 설정 → `🔄 업데이트 확인` 에서 지금 확인하거나 즉시 재시작 설치할 수 있습니다.

## 주요 기능

- **일일 보건일지** — 학생/교직원 방문 시 증상·처치·투약 기록
- **응급처치·감염병 기록** — 별도 기록지로 관리
- **학생·교직원 관리** — 엑셀 양식 일괄 업로드, 요양호·기저질환·비동의 학생 관리
- **대시보드·통계** — 일·주·월·학기·학년 단위 차트, 히트맵, 재방문 분석
- **키오스크 모드** — 태블릿에서 방문 학생 자가 접수
- **커스텀 양식** — 방문확인증·급식 요청서·진료 의뢰서 등 자유 구성
- **공공 API 연동** — 식약처 의약품 DB, 에어코리아, 기상청, 응급의료센터, 심평원, 카카오지도
- **바디맵 & 증상→처치** — 해부학적 통증 부위 선택, 증상에 따른 처치 추천
- **동료 협업** — 보건교사 2인 배치교를 위한 동일 DB 공유
- **보건실 물품 대여** — 반납 기간 알림 포함 대장 관리
- **PDF 출력** — 기간·항목 선택 출력
