오렌지톡 이관 도우미 (20260629 버전)

다른 보건일지 프로그램의 엑셀을 최적화 양식으로 변환합니다. 변환 후 "설정 → 가져오기"에 업로드하세요.
1 보건일지 엑셀 불러오기
다른 보건일지 프로그램에서 받은 엑셀 파일을 끌어다 놓거나 클릭해서 선택하세요. (.xlsx / .xls)
📂 여기에 엑셀 파일을 끌어다 놓거나 클릭하여 선택
2 학년반/학번 해석 확인
아래 코드들은 자동으로 학년·반을 알 수 없어 확인이 필요합니다. 같은 코드는 한 번만 채우면 전체에 적용됩니다.
3 변환 미리보기
최적화 양식 변환 결과입니다. 칸을 클릭해 직접 수정할 수 있습니다. 좌측 × 로 행 삭제. (노란 = 기간 첫날 임시 / 회색 = 교원·직원)
4 최적화 양식으로 내보내기
변환된 엑셀 파일을 '다운로드 폴더'에 저장합니다. 오렌지톡 프로그램의 설정 → 외부 데이터에서 업로드하여 등록 절차를 따르시기 바랍니다.
⚠ 저장한 파일을 프로그램의 설정 - 외부 데이터 - 업로드 영역에서 업로드해 주세요.
처치자 일괄 입력
처치자 이름을 적어주세요.
직위 분류 확인
학번/학년반에 발견된 직위 중 자동 인식이 안 된 것을 교원 또는 직원으로 분류해 주세요.
