표시 순서

생성된 banner.json (자동 생성 · 수정 불가)

②에서 입력하는 대로 자동으로 즉시 반영됩니다. 이 칸은 직접 수정할 수 없습니다. 아래 "내려받기"는 항상 최신 내용으로 저장됩니다.

사용 순서
  1. ① 현재 banner.json 파일을 드래그하거나 클릭해서 불러옵니다 (꼭 먼저!)
  2. ② 문구를 추가·수정합니다 (한 줄에 하나씩)
  3. 생성된 JSON 아래 "내려받기"로 banner.json 파일을 저장 → 설치파일과 함께 school114.org 다운로드 폴더에 저장 → 사용자 앱이 다음 실행 때 자동 갱신
