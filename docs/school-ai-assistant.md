# 학교용 오렌지톡 AI 도우미

개인 Gemini 키로 프로그램 사용법, 공식 의약품 설명, 일반 교육자료, 학교 보건업무 문서 작성과 가벼운 일상 대화를 돕는 교직원 전용 기능이다. 산업체용의 데스크톱 IPC → Gemini 호출, 사용법 자료 조회, 식약처 조회, 사용량 관리 구조를 참고했다. 산업체용 프로젝트를 런타임 의존성으로 사용하지 않는다.

## 사용

학교용 개발 앱을 다시 실행한 뒤 **환경설정 → API Key 관리 → 오렌지톡 AI 도우미**에서 Google AI Studio의 개인 키를 입력하고 **반영**한다. 다른 API와 같은 카드 양식이며 연결 확인·키 삭제·키 발급을 제공한다. 입력한 새 키는 반영한 뒤 연결 확인한다. **연결 확인**도 API 호출 한 번을 사용한다. 대화창의 톱니바퀴는 이 설정 화면으로 이동한다. 식약처 조회에는 기존 공공데이터포털 키와 e약은요 서비스 활용 신청이 필요하다.

AI 도우미 버튼은 기본 **우측 하단**에 표시한다. 버튼과 열린 대화창의 제목 부분을 마우스로 끌어 이동할 수 있다. 버튼을 이동하면 대화창은 버튼 근처에 배치되며 대화창 자체도 별도로 옮길 수 있다. 좌표만 `school-ai-position-v1`에 저장하며 재실행 시 복원하고 화면 크기가 줄어들면 화면 안으로 보정한다. **기본 위치**는 우측 하단 배치를 복원한다. 키보드에서는 버튼에 초점을 맞추고 Alt+방향키로 이동한다.

API 키는 주 프로세스의 `safeStorage`로 암호화하여 사용자 데이터 폴더의 `school-ai-private.json`에 저장한다. 렌더러에는 키를 반환하지 않는다. localStorage, 일반 앱 설정 DB, 커스텀 백업 등록부에 키를 넣지 않는다. 암호화가 불가능하면 평문 저장으로 우회하지 않는다. 새 PC에서는 키를 다시 등록한다. 이 파일에는 키 암호문, 앱 일일 한도와 사용량만 저장하며 질문·답변은 저장하지 않는다.

## 답변과 토큰 관리

- 모델은 `gemini-3.5-flash-lite`, API는 Interactions `/v1beta/interactions`. `store:false`이며 서버 대화 ID를 사용하지 않는다. 이 옵션은 공급자의 보안 로그나 데이터 이용 정책까지 끄는 의미가 아니다.
- 첫 요청은 범위 판정과 답변 또는 필요한 조회 선택을 함께 한다. 구조화된 범주가 허용 범위 밖이면 모델이 생성한 답변을 표시하지 않는다. 이는 모델의 의미 판정을 포함하므로 모든 우회 질문을 완벽하게 차단한다고 보장하지 않는다.
- 기능별 안내는 `school-ai-knowledge.js`에 검증된 메뉴 이름, 설명, 확인한 소스 경로를 기록한다. 전체 기능/시작 순서, AI 활용, 일지/명단/약품/감염병/응급기록, 방문 통계, 설문 작성/게시/응답, 연수 등록부/이수 현황, 홈 위젯, API, 백업, 키오스크 등 27개 안내를 제공한다. 의료기관 탐색·개인 주의사항 메모·커스텀 백업·문항 형식/번역·설문 생애주기·AI 오류 해결 안내를 세분화했다. 예전 매직 스테이션의 플래너 설명을 현재 설문·연수 탭 구성으로 수정했다.
- 띄어쓰기를 정규화하고 구체적인 기능명을 우선 검색한다. 관련 안내 최대 2개와 작은 안내 목차만 보내며 추가 안내가 필요하면 ID로 한 번 조회한다. 고정 답변을 보여주는 방식이 아니라 이 근거를 바탕으로 AI가 질문에 맞게 설명한다. 긴 입력에서는 오래된 대화와 우선순위가 낮은 안내부터 제외하며 현재 질문과 추가 조회 결과를 보존한다. 기능 변경 시 아래 갱신 검사 절차에 따라 해당 안내를 수정·검토한다.
- 질문은 2,000자, 최근 대화는 최대 4쌍 중 추정 1,800토큰 이내다. 질문당 Gemini 호출 최대 2회, 회당 추정 입력 최대 9,000토큰, 출력 한도 1,600토큰, 질문당 누적 예약 최대 24,000토큰이다. 가벼운 일상 질문은 프로그램 안내·목차와 이전 업무 대화를 제외하고 출력 한도를 512토큰(추천·설명·정리 요청은 768토큰)으로 낮춘다. 반복 재시도나 더 비싼 모델로의 자동 전환은 없다.
- 일일 앱 한도는 기존 최대값인 1,000,000토큰으로 자동 적용한다. 이전에 저장한 낮은 한도도 앱 시작 시 올리며 개인 키와 당일 사용량은 유지한다. 한도 입력, 일일/답변별 사용량 표시는 제공하지 않는다. 한국 시간 날짜로 초기화하며 호출 전 보수적 추정치를 예약하고 실제 전체 토큰으로 정산한다. 사용량을 알 수 없는 중지·시간초과·통신 오류에는 예약치를 남긴다. 이 앱 한도는 Google 계정의 사용 한도를 변경하거나 무료 이용을 보장하지 않는다.
- 범위 제한과 관련된 시스템 지침은 주 프로세스에 있으며 렌더러에서 전달하는 임의 지침·대화 기록·업무 데이터는 사용하지 않는다.

## 의약품과 개인정보

식약처 e약은요에 제품명으로 조회하며 API 키는 모델 입력에 넣지 않는다. 여러 후보가 있으면 제품명·제조사를 확인하도록 한다. 유사도만으로 제품을 선택하지 않는다. 긴 자료는 용법·금기 일부만 잘라 넣지 않고 상세 자료 전체를 제외한 사실을 알린다. 결과는 10분 동안 메모리에 최대 20건 캐시한다.

학생 명단·보건일지·현재 화면 내용은 자동으로 수집하지 않는다. 입력한 질문과 필요한 최근 대화·참고자료는 Google API로 전송한다. 직접 입력한 이메일·연락처·주민등록번호와 일부 명시적 이름 형식만 가리므로 완전한 비식별화를 보장하지 않는다. 화면에는 반복적인 안내·확인 체크박스를 두지 않으며 가림 처리나 연결 오류처럼 실제 발생한 상황만 알린다. 답변은 일반 교육·정보 탐색용이며 개별 진단·처방·복용량 판단용으로 설계하지 않았다.

대화는 메모리에만 유지하며 새 대화, 처음화면, 창 재로드, 앱 종료 시 초기화한다. 중지 또는 새 대화 이후 도착한 답변은 표시·기억하지 않는다. IPC는 `health_diary.html`을 표시하는 주 창의 최상위 프레임에서만 허용한다. 학생 키오스크와 웹 협업에는 기능과 키를 노출하지 않는다.

## 현재 범위와 확인

대화창은 520px 기본 폭과 넓게 보기, 자동 높이 입력창, 안전한 문단·강조·목록 표시, 접을 수 있는 참고자료를 제공한다. 모델의 HTML은 실행하지 않는다. Google 검색 제안만 별도의 스크립트 차단 프레임에 표시하고 외부 링크를 검증한다.

`school-ai-ui-evidence.js`는 허용 목록에 있는 배포 HTML의 버튼·탭과 설명만 읽어 질문에 맞는 항목 최대 4개를 보낸다. 주석·스크립트를 제외하며 사용자 DOM·입력값·실제 학교 기록은 읽지 않는다. 이를 통해 화면에 실제 존재하는 기능을 없다고 안내하는 오류를 줄인다.

환자 상황을 이야기하기만 한 문장은 의료 판단 요청과 구분한다. 모델이 이 경우에도 의료 요청으로 잘못 분류하면 일지 문장 정리 등 비임상 도움에 한정해 최대 한 번 다시 답하게 한다. 환자별 진단·약·처치를 요청하는 문장은 이 보정 대상이 아니다.

웹 검색에는 공개 검색어만 전달하고 최근 대화·개인 기록은 전달하지 않는다. 검색 결과를 프로그램 지식으로 영구 저장·학습하지 않으며 Google Search의 출처와 검색 제안을 함께 표시한다. 검색 호출은 질문당 최대 한 번이고 전체 Gemini 호출 최대 2회 안에 포함된다. Google 내부 검색 쿼리 수와 과금은 공급자 정책에 따른다. 참고: [Google Search grounding](https://aistudio.google.com/docs/google-search).

실제 키의 공개 예시 검사에서 의료기관 탐색 설명과 점심 추천, 단순 상황 진술에 대한 비임상 대화 응답을 확인했다. 웹 검색 실검사는 Google QUOTA 오류로 완료하지 못했다. 등록 키·원본 설정·학교 DB는 수정하지 않았으며 키를 출력하지 않았다. 격리 검사 스크립트는 `scripts/check-school-ai-live.cjs --run`이고 자동 테스트에는 포함하지 않는다.

Google Search grounding을 필요한 질문에 연결한다. 최신 공식 지침·의약품 자료·처치 교육·용어 근거를 우선 확인하며 검색하지 않은 내용을 확인했다고 말하지 않는다. 학교 내부 프로그램 기능은 웹이 아닌 배포된 안내와 화면 근거로 설명한다. 자동 주기 수집이나 모델 재학습은 하지 않는다.

`cd electron-app` 후 `npm run test:ai`로 백엔드와 Electron UI 검증을 실행한다. Electron 테스트는 `_preview/school-ai`의 격리 프로필과 가상 키·응답만 사용한다. 키 저장, 호출 범위, 개인정보 가림, 제품 모호성, 사용량 제한, 중지, 오류, 실제 앱 CSS와 좁은 화면 배치를 검증한다. 실제 개인 키를 이용한 Google 연결·답변 품질 검증은 별도로 필요하다. 이번 변경은 설치 프로그램 빌드·배포를 수행하지 않는다.

참고한 공급자 문서: [Interactions API](https://ai.google.dev/api/interactions-api), [구조화된 출력](https://ai.google.dev/gemini-api/docs/structured-output), [모델 정보](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite), [이용 약관](https://ai.google.dev/gemini-api/terms).

## 프로그램 업데이트와 안내 갱신

안내 원문은 `src/main/services/school-ai-knowledge.js`와 `school-ai-details.js`에 있으며 앱과 함께 배포된다. 모델을 영구 재학습하거나 사용자 데이터를 학습시키는 방식이 아니다. 요청에는 실행 중인 앱 버전도 포함한다.

`npm run ai:guides:check`는 안내 내용과 각 안내에 연결된 소스 파일의 SHA-256 검토본을 비교한다. 소스/안내 변경·추가·삭제를 감지하면 관련 안내 ID를 출력하며 검사에 실패한다. Windows/macOS 빌드와 개발 빌드의 prebuild, AI 테스트, GitHub Windows 배포 파이프라인에 연결되어 있다. 소스 코드를 자동으로 해석해 사용법을 지어내거나 검토 없이 해시를 덮어쓰지 않는다.

개발자가 변경 기능을 확인해 설명·버튼 이름·절차를 갱신한 뒤 `npm run ai:guides:review -- <검토한 ID들>`로 검토본을 갱신하고 `npm run test:ai`를 통과시킨다. 단순 내부 수정으로 사용법이 동일한 경우에도 해당 안내를 확인하고 검토한다. 새 기능에는 안내와 관련 소스 경로를 함께 등록한다. 이 검사는 연결된 파일의 변경을 감지하며 코드 의미를 자동으로 검증하지는 않는다.

## 일상 대화와 의료 조언 제한

2026-11-11 확인한 [Gemini API 추가 약관](https://aistudio.google.com/docs/terms)의 Use Restrictions는 임상 사용과 의료 조언 제공을 금지한다. 이 기능은 성인 교직원의 업무 도우미다. 일반적인 안부·공감·취미·취향 중심 점심 추천은 허용한다. 날씨는 사용자가 알려준 지역의 공개 예보를 검색할 수 있으며 학교의 개인 위치를 자동으로 읽지 않는다.

진단·감별·약 추천·복용량 결정·처치·환자별 등교 판단은 의료 조언으로 구분한다. 의료 단어를 포함했다는 이유로 입력을 차단하던 정규식 검사는 제거했다. 모델이 질문의 실제 목적을 답변/조회 선택과 한 번에 판단한다. 일반 의약 개념, 공식 설명서의 효능·용법·주의사항, 학생 대상 교육자료와 인용문은 정상적으로 설명한다. 순수 임상 판단 요청은 `medical_advice`로 분류해 서버의 안내로 대체하고 약품 조회·대화 저장을 하지 않는다. 혼합 질문은 안전한 교육 부분에 답하고 `medicalBoundary`로 제외한 의료 판단 부분만 짧게 안내한다. 답변 전체가 단독 복용 명령인 경우 추가 차단하며 교육 문맥의 인용문까지 일괄 차단하지 않는다. 익명/가상 사례나 면책문으로 임상 조언을 허용하지 않는다.

일반 질문은 1회 호출로 답하고, 근거가 부족할 때만 프로그램 안내(한 번에 최대 2개 ID) 또는 식약처 제품 자료를 조회해 두 번째 호출로 설명한다. 동일 제품의 후속 질문에는 직전 답변에서 사용한 10분 이내 공식 자료를 재사용해 첫 호출부터 근거로 제공한다. 다른 제품은 새로 조회하고 만료·새 대화 후에는 과거 근거를 자동으로 붙이지 않는다. 참고자료는 내부 메모리에만 보관하고, 임의 사용자 기록은 수집하지 않는다. 답변 분야에 맞는 실제 제공 자료만 출처로 표시한다. Google 검색은 첫 요청에서 모델이 필요성을 판단한 경우 두 번째 호출로 수행하며, 검색 출처와 Google 검색 제안이 없으면 근거 있는 결과로 표시하지 않는다.

형식 검사와 모델 분류에는 한계가 있으며 이 구현이나 모의 테스트가 모든 표현의 차단 또는 법적 적합성을 보증하지는 않는다. 민감정보는 입력하지 않아야 하며, 개인 건강기록을 자동 수집하지 않는다. 실제 제공 모델의 응답 평가는 별도로 필요하다.
